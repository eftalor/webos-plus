# Changelog

## 0.4.0 - 2026-11-12

- Built-in dashboard: Settings → Dashboards → Add dashboard → **LG webOS TV Plus** builds a
  page per TV (remote, picture and sound settings, TV health with the root agent).
  Options: `entity`, `sources`, `color_buttons`.
- Bundles the [LG WebOS Remote Control card](https://github.com/madmicio/LG-WebOS-Remote-Control)
  2.1.0 by madmicio, unmodified, MIT license (see `THIRD_PARTY_NOTICES.md`). An already
  installed copy (HACS) takes precedence.

## 0.3.1 - 2026-11-12

- `top_processes` adds up processes that share a name (WebAppMgr runs one per web app).

## 0.3.0 - 2026-11-12

- Optional root agent for rooted TVs (`tv/agent.sh` over SSH, forced command of a key
  generated by the integration, host key pinned on first use): free memory, memory used,
  swap used, CPU, Netflix memory, last boot, load sensors; Free memory button; the picture
  mode select reads the TV's real value.

## 0.2.1 - 2026-11-12

- Secondary entities marked as config/diagnostic, so the auto-generated Overview shows only
  the TV.

## 0.2.0 - 2026-11-12

- Media browser with app and input icons, sound mode in the media player, services
  `button`, `command`, `select_sound_output` compatible with the built-in integration.

## 0.1.0 - 2026-11-12

- First version: off instead of unavailable, built-in Wake-on-LAN with fast reconnect,
  60 s pairing window, picture/sound settings as entities (live via subscriptions, written
  without root), screen switch, input picker, power state and current app sensors.
