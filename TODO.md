## Known issues / limitations

- The remote card's sound-output popup calls `webostv.select_sound_output` (hard-coded in the
  card); use the Sound output tile instead.
- The card's 123 button and top buttons can't be hidden without modifying the card.
- Free memory: webOS relaunches Netflix in the background within about a minute
  (preloaded app), so its memory returns. Other apps stay closed.
- Picture mode without the root agent is the last value set from HA (`assumed_state`).
- Tested on one TV only (55UP7550, webOS 6.0, firmware 03.53.45, HA 2026.11).
